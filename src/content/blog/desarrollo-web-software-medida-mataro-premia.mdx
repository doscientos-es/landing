Mataró y Premià de Mar tienen empresas muy distintas: industria, servicios, comercio, cultura, restauración y proyectos digitales. Lo que suelen compartir no es el sector, sino la necesidad de trabajar con menos fricción.

## Cuándo tiene sentido pedir software a medida

Si el equipo mantiene información en varias hojas de cálculo, copia datos entre herramientas o necesita un proceso que ningún SaaS resuelve bien, merece la pena estudiar una solución propia. No siempre hay que construir desde cero: a veces basta con una web mejor conectada o una automatización pequeña.

## Una referencia cercana: Les Santes

Para [Les Santes](/projects/les-santes) desarrollamos una aplicación de evento con agenda, mapa, favoritos, recursos y un panel de gestión. El proyecto exigía una experiencia fiable incluso con mala cobertura, por eso aplicamos una arquitectura offline-first y movimos parte de la lógica al dispositivo.

La lección para cualquier empresa de Mataró o Premià es sencilla: el contexto local importa. Primero se entienden los momentos críticos del trabajo; después se elige la tecnología.

## Qué debería incluir una primera conversación

- Qué proceso consume más tiempo cada semana.
- Dónde se duplica la información.
- Qué debe seguir funcionando si falla internet.
- Qué resultado permitiría medir si el proyecto ha funcionado.

Desde nuestra base en Premià de Mar nos reunimos con empresas de Mataró, Vilassar, El Masnou y el resto del Maresme. El objetivo no es vender complejidad: es encontrar el cambio digital que tenga sentido para el negocio.
